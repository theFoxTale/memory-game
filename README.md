# 🃏 Memory Game: Русские Сказки

Интерактивная игра на поиск пар (Memory Game), разработанная в рамках этапа 1 курса [The Rolling Scopes School](https://rs.school/). Проект выполнен с соблюдением строгих требований к генерации DOM-разметки, модульной архитектуре и чистоте кода.

## ✨ Особенности проекта

- **Строгое соответствие требованиям RS School**: вся HTML-разметка генерируется исключительно через `document.createElement` и кастомную обертку `createElement`. Использование `innerHTML`, `outerHTML` и других запрещенных методов полностью исключено (контролируется через ESLint).
- **Тематические уровни**: 10 уникальных наборов карточек, основанных на русских народных и авторских сказках, находящихся в общественном достоянии (А.С. Пушкин, А.Н. Афанасьев, П.П. Ершов и др.).
- **Игровая механика**:
  - Алгоритм перемешивания Фишера-Йейтса при каждом запуске и рестарте.
  - Защита от повторных кликов и спама во время анимации несовпавших пар (таймер 700–1500 мс).
  - Мгновенный сброс состояния и отмена таймеров при нажатии «Новая игра».
- **Модальные окна**: переиспользуемый функциональный компонент для окон «Победа» и «Таблица лидеров». Закрытие по клику на оверлей, клавише `Escape` или кнопке. Блокировка прокрутки фона (`overflow: hidden`).
- **Таблица лидеров**: сохранение топ-10 лучших результатов (по количеству ходов) в `localStorage` с датой в формате ДД.ММ.ГГГГ.
- **Адаптивный дизайн**: корректное отображение на устройствах с шириной экрана от 320px до 1440px и выше.
- **Визуальный стиль**: эстетика иллюстраций Ивана Билибина (цветовая палитра, шрифты, орнаменты).

## 🚀 Начало работы

Для локального запуска и разработки вам потребуется установленный [Node.js](https://nodejs.org/) (версия 18+).

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/theFoxTale/memory-game.git
   cd memory-game
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите сервер разработки:**
   ```bash
   npm run dev
   ```
   Приложение откроется в браузере по адресу `http://localhost:5173`.

### 📜 Доступные скрипты

| Команда | Описание |
| :--- | :--- |
| `npm run dev` | Запуск локального сервера разработки с горячей перезагрузкой (HMR). |
| `npm run build` | Сборка оптимизированной версии проекта для продакшена в папку `dist`. |
| `npm run preview` | Локальный предпросмотр собранной (`build`) версии проекта. |
| `npm run lint` | Проверка кода с помощью ESLint и Stylelint. |
| `npm run lint:fix` | Автоматическое исправление ошибок линтинга, где это возможно. |
| `npm run format` | Форматирование всех файлов проекта согласно правилам Prettier. |
